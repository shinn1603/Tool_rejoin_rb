# Tool Rejoin Roblox Mobile (Fix Python 3.13)

Tool Rejoin tự động cho Roblox Mobile / Termux Android. Đã được sửa lỗi tương thích phiên bản Python 3.14 mới của Termux bằng cách tự động ghim môi trường về **Python 3.13.15**.

## 🚀 Cách cài đặt trên Termux (Chạy 1 lệnh duy nhất)

Mở Termux trên điện thoại và dán lệnh sau:

```bash
. <(curl -sL https://raw.githubusercontent.com/shinn1603/Tool_rejoin_rb/main/Setubtoolrejoin)
```

## ▶️ Cách khởi chạy Tool

Sau khi cài đặt xong, bạn có thể chạy:

- **Bản chuẩn (New Tool):**
  ```bash
  python /sdcard/Download/zamtoolrejoinnewtool.py
  ```

- **Bản VIP:**
  ```bash
  python /sdcard/Download/viprejoin.py
  ```
